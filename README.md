# The Beacon Centre website

Static five-page site for The Beacon Centre (beaconcentreglobal.com): Home, About, Services, Resources, Book.

- Open `index.html` in a browser, or host the folder on any static host.
- Styles: `assets/css/style.css`. Script: `assets/js/main.js`. Images: `assets/img/`.
- `tools/` holds the generator source (`build.py`, with its `style.css` and `main.js`) used to produce the pages.
